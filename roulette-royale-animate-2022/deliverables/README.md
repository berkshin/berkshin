# Deliverables

This folder is the output location for the native Adobe Animate file:

```text
RouletteRoyale_Animate2022.fla
```

Generate the file from inside Adobe Animate 2022 by running:

```text
tools/GenerateRouletteRoyaleFLA.jsfl
```

Only Adobe Animate can create and validate a native `.fla` document. The Linux cloud environment used to prepare this repository cannot run Adobe Animate directly.
