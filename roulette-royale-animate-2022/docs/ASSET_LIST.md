# Asset List

All assets are vector SVG files prepared for Adobe Animate import and HTML5 Canvas publishing.

| Asset | File | Purpose |
| --- | --- | --- |
| Casino Background | `assets/svg/casino_background.svg` | Dark casino backdrop with gold accent lattice |
| Gold Button | `assets/svg/button_gold.svg` | Main button chrome for Play and Spin style controls |
| European Roulette Wheel | `assets/svg/roulette_wheel_european.svg` | Single-zero European wheel art with wheel order markings |
| European Betting Table | `assets/svg/betting_table_european.svg` | Full 0-36 table plus low/even/red/black/odd/high zones |
| Chip 10 | `assets/svg/chip_10.svg` | Blue 10 Credit chip |
| Chip 50 | `assets/svg/chip_50.svg` | White 50 Credit chip |
| Chip 100 | `assets/svg/chip_100.svg` | Red 100 Credit chip |
| Chip 500 | `assets/svg/chip_500.svg` | Purple 500 Credit chip |

## Runtime-Drawn Visual Components

The game runtime also draws the following components directly on the 1920x1080 canvas to preserve crisp scaling and make the project self-contained:

- Main menu title typography and glow.
- Menu button states.
- Settings and information popups.
- Interactive roulette table zones.
- Active bet chip stacks.
- Animated roulette wheel segments.
- Animated roulette ball.
- Balance, current bet, last result, and result panels.
- Button hover glow and disabled states.

No external audio files are required. The settings system includes a sound toggle so audio cues can be added later without changing the UI contract.
